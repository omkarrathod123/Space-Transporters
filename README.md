# 🚀 Space Transporters

A 2D space‑themed transport simulation game built with **Unity 6.3**.  
Players take control of futuristic transport ships, navigating through asteroid fields, collecting resources, and delivering cargo across the galaxy.

## 🛰️ About the Project
**Space Transporters** is a Unity 2D project designed to showcase:
- Smooth transport mechanics
- Resource management gameplay
- Modular Unity project structure for easy scalability

This project is ideal for learning **Unity 2D development** and **asset management**.

## ✨ Features
- 2D space environment with parallax backgrounds
- Player‑controlled transport ships
- Cargo collection and delivery system
- Asteroid obstacles with collision physics
- Score tracking and progression system
- Modular scripts for easy extension

## 🎮 Gameplay
- Pilot your transporter ship through space.
- Avoid asteroids and hazards.
- Collect cargo pods scattered across the map.
- Deliver cargo safely to delivery area.
- Earn points and unlock new levels.
